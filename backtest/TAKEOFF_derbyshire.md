## 3. What we double-checked

Six checks on every job. Here's how this set did.

- ✅ **Every chain adds up to its printed total — 0 mm.** House: 90+2,630+90+2,120+90+
  3,420+90+2,020+90+3,590+120+5,835 = 20,185 exactly; the south positions chain hits
  20,295 exactly. Rooms: every width and depth chain above closes to 0 mm. Heights: six
  independent vertical chains all close on 2,700 exactly (300+1,500+40+560+300 ·
  450+500+1,750 · 900+150+600+1,050 · 500+1,000+300+900 · 600+2,100 · 300+1,350+150+900).
- ✅ **Opposite sides agree.** Every room closes both ways round (see the workings). The
  one apparent misfit — bed 2's 3,610 top vs 3,620 bottom — is two reference faces
  (100 vs 90 wall tick); the totals agree.
- ⚠ **Wall runs vs floor perimeter — weaker on this set, by construction.** These internal
  elevations print height chains but no run lengths, so the runs come from the plan
  chains rather than an independent sheet. The check still closes (ensuite 13,780 =
  13,780; bathroom 12,560 = 12,560) but both sides derive from the same chains — it
  proves consistency, not independence. On the control set the elevations carried their
  own runs; this practice doesn't do that.
- ✅ **Heights reconcile within each elevation.** All six chains, 0 mm (above).
- ✅ **Fixtures agree between plan and elevation.** The 1800 bath is drawn ~1,800 on the
  plan and named "CAROMA CUBE 1800MM" on IE 02; both vanity benches are 900 = 300+560+40
  on every sheet they appear; both screens are 2,100; the bathroom niche is 600 wide in
  elevation and ~600 on the plan.
- ⚠ **Sanity ranges — one range fires, with a reason.** Floors 8.4–11.2 m² ✓. But
  wall:floor is 1.34 (ensuite) and 1.82 (bathroom), below the 2.0–5.5 band the method
  expects. The reason is structural, not an error: this practice tiles 900-high bands and
  single feature walls, not floor-to-ceiling rooms — the band assumption behind that
  ratio range doesn't hold here. Every wall figure traces to a printed height, so we
  report the ratio as explained rather than suppressing the flag.
